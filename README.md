# Adrieli Mendonça — V1

React + TypeScript + Tailwind CSS + Framer Motion.

## Rodar
Instale Node.js 20+, abra a pasta no VS Code e execute:
```bash
npm install
npm run dev
```

Depois abra o endereço local mostrado pelo Vite.

## Personalizar
No `src/App.tsx`, troque `WA_LINK` e `INSTAGRAM_LINK` pelos links reais.
A logo atualmente é um wordmark provisório em texto. Quando você tiver o PNG/SVG original, podemos substituir pelo arquivo sem alterar o restante do design.
As fotos atuais são referências do Unsplash e devem ser trocadas pelas fotos reais da Adrieli antes da publicação.
